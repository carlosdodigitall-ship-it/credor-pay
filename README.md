# Credor Pay

MVP de demonstração para gestão de crédito e recebíveis.

## Estado atual

Este repositório está sendo inicializado com uma interface web responsiva para demonstração: landing page, cadastro/login de demonstração, dashboard, menu lateral recolhível e módulos locais para clientes, contratos, recebíveis e relatórios.

**Aviso:** os dados são armazenados no `localStorage` do navegador. A autenticação é simulada e não oferece segurança real. Não use dados pessoais ou financeiros reais. Antes de produção, substituir por autenticação no servidor e banco de dados com autorização por organização, auditoria e revisão regulatória.

## Desenvolvimento

```bash
npm install
npm run dev
```
